SchedEase: Class Scheduling System

Project Description

SchedEase is a simple React Native mobile application connected to Firebase Database. It allows users to 

manage class schedules using basic CRUD operations such as adding, viewing, updating, and deleting 

schedules.

The app is designed with a simple interface where users can easily organize class schedules in one 

system.

Detailed System Flow

The application starts at the home screen where the user can see two main buttons: “Add Schedule” 

and “View Schedule”.

When the user clicks “Add Schedule”, a form will appear where the user can input schedule details such 

as subject, room, day, and time. After submitting, the data is saved to the Firebase Database.

When the user clicks “View Schedule”, all saved schedules are displayed on the screen. Each schedule 

has “Update” and “Delete” buttons beside it.

The “Update” button allows the user to directly edit and save changes to the schedule, while the 

“Delete” button removes the selected schedule from the Firebase Database.

Other Details:

The project uses React Native for the mobile application and Firebase Database for storing all schedule 

data.

 Technologies Used:
